Turn Tokens

Prototype Component · v0.9 · 36 mm square

Nine double-sided tokens for turn order. The rules run two interleaved sets — one runs today; the other decides tomorrow. The two sets wear two metals so you always know which order is live: the warm Sun set (brass) and the cool Moon set (silver).

The lone Set Indicator carries the Sun on one face and the Moon on the other. Whichever face is up names today's active set; flip it at the end of each Reckoning and the sets change hands.
